Сервіс для прослуховування музики

- реєстрація та авторизація користувачів;
- онлайн-прослуховування музики;
- виставлення оцінок улюблених музикантів/колективів або окремих альбомів;
- групування аудіозаписів за категоріями (за виконавцями, альбомами, жанрами);
- рекомендація нових аудіозаписів на основі оцінених;
- оновлення матеріалів сайту (адміністративна панель сайту).
