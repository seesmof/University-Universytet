# Маркетингова компанія - Mind Map

- Аналіз цільової аудиторії (для кого робимо рекламу)
  - Аналіз переглядів наявних фільмів такого ж жанру
  - Опитування в соціальних мережах
  - Подивитись опис фільму від виробника
- Обрання каналів для просування
  - Реклама на сайтах: банери, ютуб вставки
  - Реклама в соціальних мережах: телеграм, інстаграм, фейсбук, суспільні діячі ютуб
  - Білборди по місту
  - Роздавання листівок
  - Надсилання реклами на пошту, якщо користувач підписаний на розсилку від сайту
  - Телебачення
  - Радіо
  - Кінотеатри
  - Сайт фільму, окремі сторінки в соціальних мережах

Для обрання каналів просування можна подивитись який тип рекламий краще працює в різних регіонах. Також можна подивитись які типи реклами загалом є ефективними.

Ефективні канали просування:

1. Сайти
2. Соц. мережі
3. Білборди, кінотеатри
4. Телебачення

- Розробка рекламних матеріалів (що саме будемо робити)
  - Створення самої реклами (креативні концепції, креативи)
    - Банери для сайтів
    - Зображення та повідомлення для соц. мереж
    - Зображення для білбордів та кінотеатрів
    - Відео для телебачення
- Організація заходів
  - Допрем'єрний показ на кінофестивалі
  - Прем'єра фільму
  - Прес-реліз: інтерв'ю з акторами і виробниками
  - Особисті покази, презентації
- Моніторинг та аналіз ефективності
  - Кількість переглядів фільму
  - Відгуки людей на презентаціях, переглядачів на сайтах
  - Взаємодія з рекламою на сторінках в соц. мережах (кількість лайків, репостів, переглядів)
  - Активність кінотеатру, де рекламували
  - Збори після релізу фільму
