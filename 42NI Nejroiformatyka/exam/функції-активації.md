- лінійна
  - $cx$
  - де $c$ константа
- лінійна біполярна з насиченням
  - 1, $k>a_2$,
  - Kx, $a_1 \le x \le a_2$
  - -1 , $x\lt a_1$
- лінійна уніполярна з насиченням
  - 1, $x\ge \frac{1}{2a}$
  - $ax + 0.5$, $x \lt \frac{1}{2a}$
  - 0, $x \le -\frac{1}{2a}$
- порогова -- Хевісайда
  - 1, $x\ge0$
  - 0, $x\lt0$
- порогова знакова -- біполярна
  - 1, $x\ge 0$
  - -1, $x\lt 0$
- сигмоїдна логістична -- уніполярна
  - $\displaystyle \frac{1}{1+\epsilon^{-cx}}$
- гіперболічний тангенс -- біполярна
  - $\tanh(Kx)$
- косинусоїдальна з насиченням -- уніполярна
  - 1, $x\ge \frac{\pi}{2}$
  - $\frac{1}{2} (1+\cos(x-\frac{\pi}{2}))$, $x\lt \frac{\pi}{2}$
  - 0, $x\le -\frac{\pi}{2}$
- синусоїдальна з насиченням -- біполярна
  - 1, $x\ge a$
  - $\sin(x)$, $x\lt a$
  - -1, $x\le -a$
- радіально-базисна -- Гауса
  - $\displaystyle \epsilon^{-cx^2}$
- winner take all
  - 1, $\displaystyle \phi^{(\mu, i)} \le \min_j \{\phi^{(\mu, j)}\}$
  - 0, інакше
- функція softmax
  - нормована експоненційна функція
  - стискує K-вимірний вектор $z$ до К-вимірного вектора $\sigma(z)$
  - складається з [0, 1]
  - в сумі дає 1
- функція ReLU
  - rectified linear units
  - ненасичуваний лінійний модуль
  - $\max(0, \phi)$
