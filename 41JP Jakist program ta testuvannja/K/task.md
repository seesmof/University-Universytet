1. Вибрати будь-який сайт в мережі Інтернет (магазини, салони краси тощо)
2. Провести:

- кросбраузерне тестування верстки сайту;
- тестування зручність використання сайту;
- функціональне тестування.

Для кожного виду тестування створити короткий чекліст перевірки мінімум в трьох браузерах та навести його у звіті.

3. Провести тестування з використанням інструментів розробника.
4. Провести технічне тестування з використанням Xenu Link Sleuth (або інших інструментів, наприклад, Apache JMeter).
5. Описати 7-10 знайдених дефектів у вигляді баг-репортів (для всіх інших багів у чеклістах в розділі Примітки вказати тему бага за принципом «Що? Де? Коли?»). Шаблон баг-репорта наведений на рисунку 2.1. Привласнити кожному баг-репорту свій ID, який вказати у звіті. Скріншоти самих баг-репортів навести в додатку звіту.
6. Описати 7-10 тестових випадків для функціональної частини сайту. Шаблон тест-кейсу наведений на рисунку 2.2. Привласнити кожному із тест-кейсів свій ID, який вказати у звіті. Скріншоти розроблених тест-кейсів представити у додатку звіту.
